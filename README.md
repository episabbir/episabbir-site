# episabbir-site

Personal website of Md Sabbir Ahmed, epidemiologist (Saskatchewan, Canada).

- The site is plain HTML and CSS in the main folder (index.html is the home page).
- `_source/` holds the build script and data used to generate the pages (blog posts in `blog_posts.py`, publications in `pubs.json`). It is not published.
- New blog posts: add them to the top of `_source/blog_posts.py`, rebuild, and commit.
